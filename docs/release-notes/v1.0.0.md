# مبانی کامپیوتر با C# — نسخه‌ی ۱.۰.۰ · v1.0.0

نخستین انتشار جزوه‌ی فارسی **«مبانی کامپیوتر»** با زبان **C#**؛ برای دانشجویانی که پیش از ورود به برنامه‌نویسی شیءگرا (OOP)
می‌خواهند مبانی را محکم یاد بگیرند. این نسخه هنوز **changelog** ندارد؛ پس این‌جا معرفی کلی جزوه آمده است.

**📥 دانلود:** فایل `C-Sharp-Fundamentals-v1.0.0.pdf` را از بخش **Assets** پایین همین صفحه بگیرید.

## این جزوه چیست؟

- یک جزوه‌ی آموزشی ~۱۵۰ صفحه‌ای، با ۱۴ فصل، شکل‌های مفهومی، مثال‌های قابل‌اجرا و تمرین در هر بخش.
- **جلد و پشت‌جلد رنگی** و بدنه‌ای که با **چاپ سیاه‌وسفید** هم خوانا می‌ماند.
- لحن‌های متفاوت: رسمی برای تعریف‌ها، گفت‌وگویی برای مفاهیم و «خودمونی» برای نکته‌ها.
- بخش **تمرین‌های بیشتر** در سه سطح (مبتدی، متوسط، پیشرفته) و **پاسخنامه‌ی کامل** با جدول جست‌وجوی سریع و شماره‌ی صفحه‌ی پاسخ بالای هر تمرین.

# English summary

**First release** of *Computer Fundamentals with C#* — a Persian (Farsi, RTL) handout for students who need solid
fundamentals before object-oriented programming. 14 chapters (output, variables, operators, `Math`, conversions,
decisions, loops, methods, arrays, strings, debugging), figures, per-section exercises, three-level extra exercises
and a full answer key. Built from HTML/CSS with Chromium; fonts are embedded.

- Download the PDF from the release **Assets**.
- Text & figures: CC BY-SA 4.0 · Code & tooling: MIT.
- Contributions welcome — see `CONTRIBUTING.md`.

> This release has no changelog yet because it is the first one. Later releases will list their changes here.
