# راهنمای سبک نوشتن · Style Guide

این راهنما تضمین می‌کند همه‌ی فصل‌ها، حتی با نویسنده‌های متفاوت، یکدست باشند.

## ۱. ساختار هر فصل

فایل فصل در `book/chapters/chNN.html` (**دو رقمی**: `ch01` … `ch14`) است؛ ترتیب فصل‌ها همان ترتیب الفبایی نام فایل‌هاست.

```html
<chapter n="12" title="آرایه‌ها (Array)" sub="یک زیرعنوان کوتاه"/>

<goals>
<li>هدف اول</li>
<li>هدف دوم</li>
</goals>

<h2>عنوان بخش</h2>
<p>متن...</p>
<h3>عنوان فرعی</h3>
```

ترتیب پیشنهادی هر بخش: **توضیح ← شکل ← مثال با خروجی ← کادرها ← تمرین**. هر فصل باید حداقل یک شکل و چند تمرین داشته باشد.

## ۲. کادرها

| تگ | کاربرد | لحن |
|---|---|---|
| `<imp t="عنوان">` | قاعده یا نکته‌ی **مهم** که نادیده‌گرفتنش خطا یا جواب غلط می‌دهد | رسمی/روشن |
| `<concept t="عنوان">` | تشبیه و فهم شهودی مفهوم | گفت‌وگویی |
| `<pit t="عنوان">` | **اشتباه رایج** دانشجوها | هشداردهنده |
| `<more t="عنوان">` | مطالعه‌ی بیشتر (برای امتحان الزامی نیست) | رسمی |
| `<genz t="عنوان">` | نکته‌ی «خودمونی» و ترفند | صمیمی (فقط همین‌جا) |

هر کادر یک آیکون، برچسب و سبک حاشیه‌ی متفاوت دارد تا در چاپ سیاه‌وسفید هم قابل تشخیص باشند. **هرگز معنی را فقط به رنگ نسپارید.**

## ۳. کد و خروجی

```html
<cs t="Program.cs">
int x = 5;
Console.WriteLine(x);     // 5
</cs>
<out>
5
</out>
```

- داخل `<cs>` از `<` و `>` عادی استفاده کنید (escape نکنید)؛ داخل متن عادی و `<c>` از `&lt;` و `&gt;` استفاده کنید.
- کامنت‌های داخل کد **انگلیسی** باشند.
- درون جمله از `<c>int</c>` برای کد درون‌خطی استفاده کنید؛ برای کلید صفحه‌کلید `<kbd>F5</kbd>`.
- خروجی داخل `<out>` را **حتماً** واقعاً اجرا کنید.

## ۴. شکل‌ها

در فصل: `<fig name="f_something" cap="توضیح شکل"/>` (شماره‌ی شکل خودکار است).
تابع `f_something()` در یکی از `book/figs*.py` تعریف می‌شود و یک رشته‌ی SVG برمی‌گرداند. از کمک‌های `book/figbase.py` استفاده کنید:
`svg, T (متن), R (مستطیل), L (خط), P (چندضلعی/مسیر), box, term, dia, io, proc, badge, codeblock`.

- رنگ‌ها فقط از پالت `figbase.py` (`F1…F6` برای زمینه، `S_BLUE/S_GRN/S_AMB/S_RED` برای حاشیه).
- حتماً گروه‌ها را با **الگو** (`url(#hatch)`، `url(#dots)`) یا **حاشیه‌ی خط‌چین** هم متمایز کنید، نه فقط رنگ.
- برای متن لاتین یا کد داخل SVG آرگومان `mono=True` بدهید (جهت متن را درست نگه می‌دارد).
- شکل جدید را روی نسخه‌ی کوچک‌شده هم نگاه کنید: نوشته‌ها نباید روی هم بیفتند.

## ۵. تمرین‌ها و پاسخ‌ها

```html
<ex id="12.3" t="بالاتر از میانگین">
<p>صورت تمرین...</p>
</ex>
```

- شناسه‌ی `id` به شکل `فصل.ترتیب` و **یکتا** است. تمرین‌های بخش پایانی: `B1…` (مبتدی)، `I1…` (متوسط)، `A1…` (پیشرفته) در `chapters/final.html`.
- هر تمرین باید در `chapters/answers.html` پاسخ داشته باشد:

```html
<ans id="12.3">
<cs> ...راه‌حل... </cs>
<out> ...خروجی نمونه... </out>
<p>توضیح کوتاه.</p>
</ans>
```

ترتیب پاسخ‌ها در فایل = ترتیب نمایش آن‌ها. شماره‌ی صفحه‌ی پاسخ و جدول جست‌وجوی سریع **خودکار** ساخته می‌شود.
- از ساده به سخت: هر بخش با یک مثال شروع شود و ۱ تا ۳ تمرین با دشواری افزایشی داشته باشد.
- پاسخ یک «راه‌حل نمونه» است؛ توضیح بدهید **چرا** کار می‌کند، نه فقط کد.

## ۶. لحن و زبان

- **رسمی و کتابی** برای تعریف‌ها و قواعد؛ **گفت‌وگویی و ساده** برای توضیح مفاهیم؛ **خودمونی** فقط در `<genz>`.
- جمله‌ها کوتاه و روشن؛ اصطلاح انگلیسی را در اولین استفاده کنار معادل فارسی بیاورید: «متغیر (Variable)».
- بدون طعنه یا تحقیر؛ مخاطب تازه‌کار است.

## ۷. نگارش فارسی

- از **نیم‌فاصله** (ZWNJ) درست استفاده کنید: «می‌شود»، «کتاب‌ها»، «برنامه‌نویسی»، «سی‌شارپ».
- حروف عربی «ي» و «ك» ممنوع؛ از «ی» و «ک» فارسی استفاده کنید.
- ارقام داخل متن فارسی، **فارسی** (۱۲۳) و داخل کد و خروجی، **لاتین** (123).
- نام‌های لاتین مثل `.NET` یا `C# 14` را همان‌طور بنویسید؛ ابزار ساخت جهت آن‌ها را خودکار درست می‌کند.
- نام نویسنده: فارسی «مهران قدیریان» و انگلیسی «Mehran Ghadirian».
