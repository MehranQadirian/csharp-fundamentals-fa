    برای کار با آرایه به حلقه‌ها (فصل ۱۰) و برای نوشتن توابع کاربردی روی آن‌ها به متدها (فصل ۱۱) نیاز دارید. این فصل پیش از فصل رشته‌هاست، چون رشته‌ها خودشان با آرایه‌ها (Split و ToCharArray) ارتباط نزدیک دارند.

    چرا آرایه؟

    فرض کنید نمره‌ی ۳۰ دانشجو را می‌خواهید ذخیره و میانگین بگیرید. آیا باید ۳۰ متغیر s1 تا s30 بسازید؟ و اگر ۳۰۰ نفر بودند؟ آرایه (Array) راه‌حل است: یک متغیر که چندین مقدار هم‌نوع را پشت‌سرهم و با شماره نگه می‌دارد.

    آرایه مثل یک ردیف قفسه (لاکر) در مدرسه است: همه‌ی قفسه‌ها یک‌اندازه‌اند (هم‌نوع)، تعدادشان از اول مشخص است (اندازه‌ی ثابت) و هر قفسه یک شماره دارد که از صفر شروع می‌شود. اگر بخواهید به قفسه‌ی شماره‌ی ۳ بروید، بدون جست‌وجو یک‌راست می‌روید؛ به همین دلیل دسترسی به آرایه بسیار سریع است.

    ۱) هم‌نوع: همه‌ی خانه‌ها یک نوع دارند. ۲) اندازه‌ی ثابت: پس از ساخت، تعداد خانه‌ها عوض نمی‌شود. ۳) اندیس از صفر: خانه‌ها 0 تا Length-1 شماره‌گذاری می‌شوند.

    ساخت و مقداردهی

    int[] scores = new int[5]; // 5 cells, all 0 int[] a = { 12, 7, 19, 3, 15 }; // size from the initializer int[] b = new int[] { 4, 8, 15 }; // same, longer form int[] c = [1, 2, 3]; // collection expression (C# 12) Console.WriteLine(scores[0]); // 0 Console.WriteLine(a.Length); // 5 Console.WriteLine(a[0]); // 12 Console.WriteLine(a[^1]); // 15 (last) a[2] = 20; // change a cell Console.WriteLine(a[2]); // 20 0 5 12 15 20
    نوع آرایهمقدار پیش‌فرض هر خانه
    int[]، long[]0
    double[]، float[]0.0
    bool[]false
    char[]'\0' (کاراکتر تهی)
    string[]null (نه رشته‌ی خالی!)

    آرایه‌ی ۵ خانه‌ای خانه‌های 0 تا 4 دارد. نوشتن a[5] یا a[-1] در زمان اجرا IndexOutOfRangeException می‌دهد. آخرین خانه همیشه a[a.Length - 1] یا a[^1] است، نه a[a.Length].

    آرایه‌ی { 4, 8, 15, 16, 23 } را بسازید. هر عنصر را به‌صورت a[i] = ... و سپس عنصرها را از آخر به اول (در یک خط) چاپ کنید.

    پیمایش آرایه

    آرایه و حلقه جدایی‌ناپذیرند. اگر شماره‌ی خانه لازم است از for و اگر فقط مقدارها را می‌خواهید از foreach استفاده کنید.

    int[] a = { 12, 7, 19, 3, 15 }; for (int i = 0; i < a.Length; i++) Console.Write($"[{i}]={a[i]} "); Console.WriteLine(); foreach (int x in a) Console.Write(x + " "); Console.WriteLine(); [0]=12 [1]=7 [2]=19 [3]=3 [4]=15 12 7 19 3 15

    متغیر حلقه‌ی foreach یک کپی از مقدار هر خانه است و نمی‌توان آن را تغییر داد (CS1656). برای تغییر دادن خانه‌ها از for و اندیس استفاده کنید: a[i] = a[i] * 2;.

    الگوریتم‌های پایه

    جمع، میانگین، بیشینه و کمینه

    int[] a = { 12, 7, 19, 3, 15 }; int sum = 0, max = a[0], min = a[0]; foreach (int x in a) { sum += x; if (x > max) max = x; if (x < min) min = x; } double avg = (double)sum / a.Length; Console.WriteLine($"sum={sum} avg={avg} max={max} min={min}"); sum=56 avg=11.2 max=19 min=3

    مقدار اولیه‌ی max و min را عنصر اول بگذارید (نه ۰). اگر همه‌ی عددها منفی باشند و max = 0 بگذارید، جواب غلط می‌شود.

    جست‌وجوی خطی

    int[] a = { 12, 7, 19, 3, 15 }; int target = 19, index = -1; for (int i = 0; i < a.Length; i++) { if (a[i] == target) { index = i; break; } } Console.WriteLine(index); // 2 (-1 means not found) 2

    برعکس‌کردن در جا

    int[] a = { 1, 2, 3, 4, 5 }; for (int i = 0, j = a.Length - 1; i < j; i++, j--) { int temp = a[i]; a[i] = a[j]; a[j] = temp; // swap through a temporary variable } Console.WriteLine(string.Join(" ", a)); 5 4 3 2 1

    برای عوض کردن دو مقدار، به‌جای temp می‌تونی از این ترفند استفاده کنی: (a[i], a[j]) = (a[j], a[i]);. همان تعویض را با یک خط انجام می‌دهد 😎

    پنج عدد حقیقی را از کاربر در یک آرایه‌ی double[] بگیرید و جمع، میانگین، بزرگ‌ترین و کوچک‌ترین را چاپ کنید.

    ده عدد صحیح بگیرید و فقط عددهایی را که از میانگین بزرگ‌ترند چاپ کنید، همراه با تعدادشان.

    عددی بگیرید و در آرایه‌ی { 5, 3, 8, 3, 9, 3 } بگویید اولین بار در کدام اندیس است یا «پیدا نشد». سپس همه‌ی اندیس‌هایش را چاپ کنید.

    آرایه‌ی { 1, 2, 3, 4, 5 } را الف) بدون Array.Reverse برعکس کنید؛ ب) یک واحد به چپ بچرخانید (نتیجه: 2 3 4 5 1).

    ابزارهای آماده‌ی کلاس Array

    int[] b = { 5, 2, 9, 1 }; Array.Sort(b); Console.WriteLine(string.Join(", ", b)); // 1, 2, 5, 9 Array.Reverse(b); Console.WriteLine(string.Join(", ", b)); // 9, 5, 2, 1 Console.WriteLine(Array.IndexOf(b, 5)); // 1 (-1 if missing) Console.WriteLine(b.Contains(2)); // True Console.WriteLine(b.Max() + " " + b.Min() + " " + b.Sum()); // 9 1 17 Array.Fill(b, 0); Console.WriteLine(string.Join(", ", b)); // 0, 0, 0, 0 1, 2, 5, 9 9, 5, 2, 1 1 True 9 1 17 0, 0, 0, 0
    دستورکار
    Array.Sort(a)مرتب‌سازی صعودی (خود آرایه تغییر می‌کند)
    Array.Reverse(a)برعکس‌کردن در جا
    Array.IndexOf(a, x)اندیس اولین x یا -1
    Array.Fill(a, x)پرکردن همه‌ی خانه‌ها با x
    Array.Copy(src, dst, n)کپی n خانه از src به dst
    a.Max() / Min() / Sum()بیشینه / کمینه / جمع (با LINQ؛ در قالب پیش‌فرض کنسول آماده است)

    در تمرین‌ها و آزمون‌ها معمولاً الگوریتم دستی خواسته می‌شود تا منطق را یاد بگیرید؛ در پروژه‌های واقعی از ابزارهای آماده استفاده کنید چون سریع‌تر، کوتاه‌تر و کم‌خطاترند. Max()، Sum() و Contains() از کتابخانه‌ی LINQ می‌آیند.

    آرایه یک ارجاع است

    برخلاف int و double که مقدارشان درون خود متغیر است، متغیر آرایه فقط آدرس آرایه را نگه می‌دارد. پس int[] b = a; آرایه را کپی نمی‌کند؛ فقط یک نام دوم برای همان آرایه می‌سازد.

    int[] a = { 1, 2, 3 }; int[] b = a; // alias, NOT a copy b[0] = 10; Console.WriteLine(a[0]); // 10 int[] c = (int[])a.Clone(); // real copy (also: int[] c = [.. a];) c[1] = 20; Console.WriteLine(string.Join(",", a)); // 10,2,3 Console.WriteLine(string.Join(",", c)); // 10,20,3 Console.WriteLine(a == b); // True (same array) Console.WriteLine(a == c); // False (equal values, different arrays) 10 10,2,3 10,20,3 True False

    برای آرایه‌ها == فقط می‌پرسد «آیا این دو یک آرایه‌اند؟» و محتوا را نمی‌سنجد. برای مقایسه‌ی محتوا از a.SequenceEqual(b) یا حلقه استفاده کنید.

    خروجی کد را پیش‌بینی کنید و بگویید چرا:

    int[] a = { 1, 2, 3 }; int[] b = a; b[0] = 10; int[] c = (int[])a.Clone(); c[1] = 20; Console.WriteLine(string.Join(",", a)); Console.WriteLine(string.Join(",", b)); Console.WriteLine(string.Join(",", c)); Console.WriteLine(a == b); Console.WriteLine(a == c);

    آرایه و متد

    چون آرایه ارجاع است، وقتی آن را به متد می‌دهید، متد به همان آرایه دسترسی دارد و تغییراتش بعد از بازگشت هم دیده می‌شود. متد می‌تواند آرایه برگرداند.

    static int Max(int[] arr) { int m = arr[0]; foreach (int x in arr) if (x > m) m = x; return m; } static void DoubleAll(int[] arr) // changes the caller's array { for (int i = 0; i < arr.Length; i++) arr[i] *= 2; } static int[] Squares(int n) // returns a new array { int[] r = new int[n]; for (int i = 0; i < n; i++) r[i] = (i + 1) * (i + 1); return r; } int[] nums = { 1, 2, 3 }; DoubleAll(nums); Console.WriteLine(string.Join(" ", nums)); // 2 4 6 Console.WriteLine(Max(nums)); // 6 Console.WriteLine(string.Join(" ", Squares(4))); // 1 4 9 16 2 4 6 6 1 4 9 16

    با کلمه‌ی params می‌توان متدی نوشت که هر تعداد آرگومان بگیرد: static int Sum(params int[] v) را می‌توان هم با Sum(1, 2, 3) و هم با Sum(arr) صدا زد. خود Console.WriteLine و string.Format هم همین‌طور کار می‌کنند.

    عدد 122331 را بگیرید و با یک آرایه‌ی int[10] شمارنده، بگویید هر رقم چند بار تکرار شده (فقط ارقام غایب را چاپ نکنید). راهنمایی: cnt[n % 10]++.

    بدون مرتب‌سازی و فقط با یک پیمایش، دومین مقدار بزرگ در { 5, 9, 2, 9, 7 } را پیدا کنید (منظور بزرگ‌ترین مقداری است که از بیشینه کوچک‌تر است؛ در این مثال ۷).

    آرایه‌ی دوبعدی (ماتریس)

    گاهی داده‌ها جدول‌اند: نمره‌ی چند دانشجو در چند درس، صفحه‌ی شطرنج، تصویر. برای این‌ها از آرایه‌ی دوبعدی استفاده می‌شود که با دو اندیس (سطر و بعد ستون) خوانده می‌شود.

    int[,] m = { { 1, 2, 3 }, { 4, 5, 6 } }; Console.WriteLine(m.GetLength(0)); // 2 rows Console.WriteLine(m.GetLength(1)); // 3 columns Console.WriteLine(m[1, 2]); // 6 int sum = 0; for (int r = 0; r < m.GetLength(0); r++) { for (int c = 0; c < m.GetLength(1); c++) { Console.Write(m[r, c] + " "); sum += m[r, c]; } Console.WriteLine(); } Console.WriteLine("sum = " + sum); 2 3 6 1 2 3 4 5 6 sum = 21

    همان‌طور که در فصل ۱۰ دیدید، حلقه‌ی بیرونی «سطرها» و حلقه‌ی درونی «ستون‌های هر سطر» است. برای هر سطر، همه‌ی ستون‌ها کامل پیمایش می‌شوند و بعد سطر بعدی شروع می‌شود، دقیقاً مثل خواندن خط‌به‌خط یک جدول.

    ماتریس { {1,2,3}, {4,5,6}, {7,8,9} } را بسازید و الف) مجموع قطر اصلی، ب) مجموع هر سطر، ج) ترانهاده (جابه‌جایی سطر و ستون) را چاپ کنید.

    دو آرایه‌ی مرتب { 1, 4, 9 } و { 2, 3, 10 } را در آرایه‌ای تازه ادغام کنید که مرتب بماند (بدون Array.Sort): 1 2 3 4 9 10. با دو اشاره‌گر حل کنید.

    مطالعه‌ی بیشتر

    آرایه‌ی دندانه‌دار، آرایه‌ای از آرایه‌هاست که هر سطر می‌تواند طول متفاوتی داشته باشد: int[][] j = new int[3][]; سپس j[0] = new int[] { 1 }; و j[1] = new int[] { 2, 3 }; و دسترسی با j[1][0]. برای مثلث پاسکال یا داده‌های نامنظم مناسب است.

    اندازه‌ی آرایه پس از ساخت عوض نمی‌شود. اگر تعداد داده‌ها را از قبل نمی‌دانید، از List<int> استفاده کنید: var list = new List<int>();، list.Add(5);، list.Count، list[0]، list.Remove(5);. همه‌ی ایده‌های این فصل (اندیس، حلقه، جست‌وجو) در List هم به همین شکل کار می‌کند؛ فقط به‌جای Length از Count استفاده می‌شود.

    برای پرکردن آرایه با عدد تصادفی: for (int i = 0; i < a.Length; i++) a[i] = Random.Shared.Next(1, 101); (عدد ۱ تا ۱۰۰). برای آزمایش الگوریتم‌ها بسیار مفید است.

    ساختن: new int[n] یا { ... } · طول: Length · آخرین: a[^1] · پیمایش: for / foreach · کپی: Clone() · مرتب‌سازی: Array.Sort · دوبعدی: [r, c] و GetLength. وقتی خطای IndexOutOfRange دیدی، اول Length و آخرین اندیس رو چک کن 😉
