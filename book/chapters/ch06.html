    عملگر و عملوند

    عملگر (Operator) نماد یک عمل است و عملوند (Operand) چیزی است که عمل روی آن انجام می‌شود. در 3 + 4 علامت + عملگر و اعداد 3 و 4 عملوندند. عملگرها بر اساس تعداد عملوند دسته‌بندی می‌شوند:

    نوعتعداد عملوندمثال
    یکانی (Unary)یک عملوند-x , x++ , !ok
    دوتایی (Binary)دو عملوندa + b , a % b
    سه‌تایی (Ternary)سه عملوندcond ? a : b (فصل ۹)

    عملگرهای حسابی

    عملگرناممثالنتیجه
    +جمع8 + 311
    -تفریق8 - 35
    *ضرب8 * 324
    /تقسیم8 / 3   8.0 / 32    2.6666666666666665
    %باقی‌مانده (Modulo)8 % 32

    تقسیم: صحیح یا اعشاری؟

    نتیجه‌ی / به نوع عملوندها بستگی دارد، نه به مقدارشان. اگر هر دو عملوند صحیح باشند، تقسیم صحیح انجام می‌شود و قسمت اعشاری حذف می‌شود. اگر دست‌کم یکی اعشاری باشد، تقسیم اعشاری است.

    Console.WriteLine(17 / 5); // 3 (both are int) Console.WriteLine(17 % 5); // 2 Console.WriteLine(17.0 / 5); // 3.4 (one is double) Console.WriteLine(17 / 5.0); // 3.4 Console.WriteLine(-17 / 5); // -3 (the fraction is cut toward zero) Console.WriteLine(-17 % 5); // -2 (sign follows the left operand) Console.WriteLine(17 % -5); // 2 Console.WriteLine(5.5 % 2); // 1.5 (% also works with doubles) 3 2 3.4 3.4 -3 -2 2 1.5

    میانگین دو عدد صحیح: double avg = (3 + 4) / 2; نتیجه 3 است نه 3.5! چون ابتدا 7 / 2 به‌صورت صحیح حساب می‌شود (می‌شود 3) و سپس 3 به double تبدیل می‌شود. راه‌حل: (3 + 4) / 2.0 یا (double)(3 + 4) / 2.

    تقسیم بر صفر

    int zero = 0; // Console.WriteLine(10 / zero); // crash: DivideByZeroException Console.WriteLine(10.0 / zero); // Infinity Console.WriteLine(-10.0 / zero); // -Infinity Console.WriteLine(0.0 / zero); // NaN (Not a Number) Infinity -Infinity NaN

    تقسیم صحیح بر صفر در زمان اجرا استثنا می‌دهد (DivideByZeroException) و برنامه متوقف می‌شود؛ اما تقسیم اعشاری بر صفر خطا نمی‌دهد و Infinity یا NaN برمی‌گرداند. اگر مقسوم‌علیه ممکن است صفر باشد، قبل از تقسیم آن را بررسی کنید (فصل ۹).

    باقی‌مانده کجا به کار می‌آید؟

    در نگاه اول % عملگر عجیبی است، اما در عمل یکی از پرکاربردترین عملگرهاست:

    کاربردکد
    زوج/فرد بودن (زوج اگر نتیجه ۰ باشد)n % 2
    بخش‌پذیری (مثلاً مضرب ۵ بودن)n % 5 == 0
    رقم یکان یک عددn % 10
    حذف رقم یکانn / 10
    چرخش در یک بازه (ساعت، روز هفته، اندیس آرایه)(start + step) % size
    int n = 4729; Console.WriteLine(n % 10); // 9 last digit Console.WriteLine(n / 10); // 472 without the last digit Console.WriteLine(n / 10 % 10); // 2 tens digit Console.WriteLine(n / 100 % 10); // 7 hundreds digit 9 472 2 7

    دو عملگر / و % روی اعداد صحیح مثل یک «جداکننده» عمل می‌کنند. n / 10 یعنی «رقم آخر را دور بریز» و n % 10 یعنی «فقط رقم آخر را نگه دار». با تکرار این دو می‌توان رقم‌های یک عدد را یکی‌یکی جدا کرد؛ ایده‌ای که در فصل حلقه‌ها خیلی استفاده می‌کنیم.

    اولویت و شرکت‌پذیری

    وقتی چند عملگر در یک عبارت باشند، سی‌شارپ طبق جدول اولویت عمل می‌کند. اگر اولویت برابر باشد، معمولاً از چپ به راست (شرکت‌پذیری چپ) پیش می‌رود، به‌جز تخصیص که از راست به چپ است.

    Console.WriteLine(2 + 3 * 4); // 14 * first Console.WriteLine((2 + 3) * 4); // 20 parentheses first Console.WriteLine(10 - 4 - 3); // 3 left to right: (10-4)-3 Console.WriteLine(20 / 4 * 2); // 10 (20/4)*2 Console.WriteLine(2 + 3 * 4 % 5); // 4 3*4=12, 12%5=2, 2+2 int a, b; a = b = 7; // right to left: b=7 then a=b 14 20 3 10 4

    جدول اولویت رو حفظ نکن! هرجا کوچک‌ترین شکی داشتی پرانتز بذار. پرانتز اضافه خطا نیست، ولی «به‌هم‌ریختنِ خواننده» حتماً خطاست. کد خوب برای فهمیده شدن نوشته می‌شه، نه برای نشون‌دادنِ حفظیات.

    عملگرهای تخصیص ترکیبی

    عملگرمعادلتوضیح (با x = 10)
    x += 3x = x + 3x می‌شود 13
    x -= 3x = x - 3x می‌شود 7
    x *= 3x = x * 3x می‌شود 30
    x /= 3x = x / 3x می‌شود 3 (تقسیم صحیح)
    x %= 3x = x % 3x می‌شود 1

    افزایش و کاهش (Increment / Decrement)

    دستور x++ یعنی «یک واحد به x اضافه کن» و x-- یعنی «یکی کم کن». این عملگرها دو شکل دارند و وقتی داخل یک عبارت بزرگ‌تر قرار بگیرند فرق دارند:

    int x = 5; int y = x++; // y gets 5, then x becomes 6 Console.WriteLine($"x={x}, y={y}"); x = 5; y = ++x; // x becomes 6, then y gets 6 Console.WriteLine($"x={x}, y={y}"); x = 5; x = x++; // x stays 5 (!) Console.WriteLine(x); x=6, y=5 x=6, y=6 5

    خط x = x++; مقدار x را عوض نمی‌کند: ابتدا مقدار قدیمی (5) به‌عنوان نتیجه‌ی عبارت برمی‌گردد، x به 6 می‌رسد، اما بعد نتیجه (5) دوباره در x تخصیص داده می‌شود. بهتر است ++ را در یک دستور مستقل (x++;) یا در حلقه‌ها استفاده کنید و داخل عبارت‌های پیچیده نیاورید.

    ترکیب انواع در محاسبه

    در یک عبارت حسابی، اگر دو عملوند هم‌نوع باشند، نتیجه هم از همان نوع است. اگر نه، عملوند «کوچک‌تر» به نوع «بزرگ‌تر» ارتقا می‌یابد:

    عبارتنوع نتیجهتوضیح
    int + intintهمان نوع
    int + doubledoubleint به double ارتقا می‌یابد
    int + longlongنوع بزرگ‌تر برنده است
    byte + byteintانواع کوچک‌تر از int قبل از محاسبه به int تبدیل می‌شوند
    char + intint'A' + 1 برابر 66 است، نه 'B'
    byte p = 100, q = 50; // byte r = p + q; // error CS0266: result is int, not byte byte r = (byte)(p + q); // explicit cast (chapter 8) int sum = p + q; // simpler: keep it in an int

    عملگرهای بیتی روی «بیت‌های» یک عدد کار می‌کنند و در برنامه‌نویسی سطح پایین، رمزنگاری و فلگ‌ها کاربرد دارند. با a = 5 (در مبنای ۲: 101) و b = 3 (011):

    عملگرناممثالنتیجه
    &و بیتی5 & 31
    |یا بیتی5 | 37
    ^یای انحصاری (XOR)5 ^ 36
    ~نقیض بیتی~5-6
    <<شیفت به چپ (× 2 برای هر بار)1 << 38
    >>شیفت به راست (÷ 2 برای هر بار)16 >> 24

    مقدار هر عبارت را بدون اجرا پیدا کنید، سپس در برنامه امتحان کنید:

    7 / 2  ·  7 % 2  ·  -7 / 2  ·  -7 % 2  ·  7 / 2.0  ·  2 + 3 * 4 % 5  ·  10 - 4 - 3  ·  (10 - 4) * 2 / 5

    یک عدد سه‌رقمی (مثلاً 482) در متغیر بگذارید و رقم‌های صدگان، دهگان و یکان آن و مجموع رقم‌ها را چاپ کنید. فقط از / و % استفاده کنید.

    تعداد ثانیه (مثلاً 3725) را به قالب h:m:s تبدیل و چاپ کنید (برای 3725 باید «1 ساعت و 2 دقیقه و 5 ثانیه» بیاید).

    بدون استفاده از متغیر سوم، مقدار دو متغیر a و b را فقط با جمع و تفریق جابه‌جا کنید. جدول ردیابی هم بکشید. سپس توضیح دهید چرا این روش برای انواع بزرگ می‌تواند خطرناک باشد.

    مقدار نهایی x و y و z چقدر است؟

    int x = 5; int y = x++ * 2; int z = ++x * 2;
