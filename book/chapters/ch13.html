    تقریباً هر برنامه‌ای با متن سروکار دارد: نام کاربری، ایمیل، رمز عبور، جست‌وجو، پیام‌ها و فایل‌ها. هر چه رشته‌ها را بهتر بشناسید، برنامه‌های واقعی را سریع‌تر می‌نویسید. فصل‌های ۸ (تبدیل نوع و char)، ۱۰ (حلقه‌ها)، ۱۱ (متدها) و ۱۲ (آرایه‌ها) پیش‌نیاز این فصل‌اند.

    رشته چیست؟

    رشته (string) دنباله‌ای مرتب از کاراکترها (char) است که میان دو علامت نقل‌قول دوتایی " " نوشته می‌شود. هر رشته یک طول دارد (Length) و هر کاراکتر آن یک اندیس که از صفر شروع می‌شود.

    string name = "Sara"; string empty = ""; // empty string: length 0 string none = null; // no string at all Console.WriteLine(name.Length); // 4 Console.WriteLine(empty.Length); // 0 Console.WriteLine(string.IsNullOrEmpty(none)); // True Console.WriteLine(string.IsNullOrWhiteSpace(" ")); // True 4 0 True True

    رشته مثل یک قطار است که هر واگن آن یک کاراکتر دارد و شماره‌ی واگن‌ها از ۰ شروع می‌شود. «طول» تعداد واگن‌هاست، پس آخرین واگن شماره‌ی Length - 1 دارد. رشته‌ی خالی "" قطاری بدون واگن است، اما null یعنی اصلاً قطاری وجود ندارد!

    اگر s برابر null باشد، s.Length استثنای NullReferenceException می‌دهد، ولی برای "" مقدار ۰ برمی‌گرداند. برای ورودی‌های نامطمئن از string.IsNullOrEmpty یا string.IsNullOrWhiteSpace استفاده کنید.

    رشته‌ی "Programming" را در یک متغیر بگذارید و طول، کاراکتر اول، آخر و وسط آن را چاپ کنید.

    اندیس، برش و بازه

    string s = "Hello"; Console.WriteLine(s[0]); // H Console.WriteLine(s[4]); // o Console.WriteLine(s[^1]); // o (last) Console.WriteLine(s[^2]); // l (second from last) Console.WriteLine(s.Substring(1, 3)); // ell (start, length) Console.WriteLine(s.Substring(2)); // llo (to the end) Console.WriteLine(s[1..4]); // ell (start..end, end excluded) Console.WriteLine(s[..2]); // He Console.WriteLine(s[3..]); // lo H o o l ell llo ell He lo
    عبارتمعنی
    s[i]کاراکتر شماره‌ی i (فقط خواندنی)؛ i باید بین ۰ و Length-1 باشد.
    s[^k]کاراکتر k‌ام از انتها (^1 یعنی آخرین کاراکتر).
    s.Substring(a, n)از اندیس a، تعداد n کاراکتر.
    s.Substring(a)از اندیس a تا آخر رشته.
    s[a..b]از اندیس a تا قبل از b (اندیس b شامل نمی‌شود).

    برای "Hello" دستور s[5] یا s.Substring(3, 5) استثنا می‌دهد (IndexOutOfRangeException / ArgumentOutOfRangeException). اندیس آخر همیشه Length - 1 است، نه Length. قبل از دسترسی، طول را بررسی کنید.

    رشته‌ی "2026-11-06" را با Substring به سال، ماه و روز بشکنید و به‌صورت 06/11/2026 چاپ کنید.

    پیمایش رشته با حلقه

    چون رشته دنباله‌ای از کاراکترهاست، با for (وقتی اندیس لازم است) یا foreach (وقتی فقط خود کاراکتر لازم است) می‌توان آن را پیمایش کرد. متدهای ایستای char مثل IsLetter، IsDigit، IsUpper، IsLower و IsWhiteSpace برای دسته‌بندی کاراکترها کار می‌آیند.

    string input = "Abc123 xyZ!"; int letters = 0, digits = 0, upper = 0; foreach (char c in input) { if (char.IsLetter(c)) letters++; if (char.IsDigit(c)) digits++; if (char.IsUpper(c)) upper++; } Console.WriteLine($"Letters={letters} Digits={digits} Upper={upper}"); for (int i = input.Length - 1; i >= 0; i--) // reverse print Console.Write(input[i]); Console.WriteLine(); Letters=6 Digits=3 Upper=2 !Zyx 321cbA

    عبارت 'a' + 'b' رشته‌ی "ab" نمی‌سازد؛ مقدار ۱۹۵ (۹۷ + ۹۸) می‌شود. برای چسباندن، حداقل یکی از طرفین باید string باشد: "" + 'a' + 'b' یا $"{'a'}{'b'}".

    رشته‌ای از کاربر بگیرید و تعداد حروف، ارقام، فاصله‌ها و سایر نمادها را جداگانه چاپ کنید.

    تغییرناپذیری (Immutability)

    مهم‌ترین ویژگی رشته‌ها در سی‌شارپ این است: رشته‌ها پس از ساخته‌شدن تغییر نمی‌کنند. متدهایی مثل ToUpper یا Replace رشته‌ی اصلی را عوض نمی‌کنند؛ یک رشته‌ی جدید برمی‌گردانند و باید آن را ذخیره کنید.

    string s = "abc"; s.ToUpper(); // result thrown away! Console.WriteLine(s); // abc s = s.ToUpper(); // keep the result Console.WriteLine(s); // ABC // s[0] = 'X'; // error CS0200: read-only indexer abc ABC

    رشته مثل متنی است که روی سنگ حک شده؛ نمی‌توانی یک حرفش را پاک کنی. اگر بخواهی چیزی را عوض کنی، یک سنگ جدید می‌سازی و می‌گویی «از این به بعد این سنگ را نگاه کن». متغیر s فقط یک برچسب است که می‌تواند از یک سنگ به سنگ دیگر برود.

    جست‌وجو در رشته

    string t = "banana"; Console.WriteLine(t.IndexOf('a')); // 1 (first) Console.WriteLine(t.IndexOf("na")); // 2 Console.WriteLine(t.IndexOf('a', 2)); // 3 (search from index 2) Console.WriteLine(t.LastIndexOf('a')); // 5 Console.WriteLine(t.IndexOf('z')); // -1 (not found) Console.WriteLine(t.Contains("nan")); // True Console.WriteLine(t.StartsWith("ba")); // True Console.WriteLine(t.EndsWith("na")); // True 1 2 3 5 -1 True True True

    متدهای IndexOf و LastIndexOf وقتی چیزی پیدا نکنند -1 برمی‌گردانند، نه استثنا. پیش از استفاده از نتیجه به‌عنوان اندیس، حتماً != -1 را بررسی کنید.

    ایمیلی از کاربر بگیرید. اگر دقیقاً یک @ داشت، @ نه اول و نه آخر بود و بعد از @ حداقل یک نقطه وجود داشت، «معتبر» وگرنه «نامعتبر» چاپ کنید.

    ویرایش: برش، جایگزینی، تراز و ...

    string u = " Hello World "; Console.WriteLine($"[{u.Trim()}]"); // [Hello World] Console.WriteLine($"[{u.TrimStart()}]"); // [Hello World ] Console.WriteLine($"[{u.TrimEnd()}]"); // [ Hello World] Console.WriteLine("Hello".ToUpper()); // HELLO Console.WriteLine("Hello".ToLower()); // hello Console.WriteLine("Hello World".Replace("World", "C#")); // Hello C# Console.WriteLine("Hello".Replace('l', 'L')); // HeLLo Console.WriteLine("Hello".Remove(1, 2)); // Hlo Console.WriteLine("Hello".Insert(5, "!")); // Hello! Console.WriteLine("7".PadLeft(3, '0')); // 007 Console.WriteLine("ab".PadRight(5, '.') + "|"); // ab...| [Hello World] [Hello World ] [ Hello World] HELLO hello Hello C# HeLLo Hlo Hello! 007 ab...|
    متدکار
    Trim / TrimStart / TrimEndحذف فاصله‌ی اضافی از دو سر / ابتدا / انتها
    ToUpper / ToLowerتبدیل به حروف بزرگ / کوچک انگلیسی
    Replace(a, b)جایگزینی همه‌ی a ها با b
    Remove(i, n)حذف n کاراکتر از اندیس i
    Insert(i, x)درج x در اندیس i
    PadLeft / PadRight(n, c)پرکردن با c تا طول n (برای ترازکردن و صفر اول)

    هیچ‌کدوم از این متدها خودِ رشته رو عوض نمی‌کنن. هر وقت دیدی s.Trim(); رو نوشتی و هیچ اتفاقی نیفتاد، یادت بیاد که باید بنویسی s = s.Trim(); 😉

    نام کامل را از کاربر بگیرید (مثلاً " aLi rEZAEI ") و به‌صورت Ali Rezaei چاپ کنید: فاصله‌های اضافه حذف و حرف اول هر کلمه بزرگ و بقیه کوچک شود.

    شکستن و چسباندن: Split و Join

    Split نتیجه را در یک string[] می‌گذارد. این یک آرایه است؛ یعنی چند رشته‌ی پشت‌سرهم که با اندیس (parts[0]) و با .Length قابل دسترسی‌اند. آرایه‌ها را در فصل قبل (۱۲) خوانده‌اید؛ این‌جا همان string[] است.

    string csv = "Ali,Sara,Reza"; string[] parts = csv.Split(','); Console.WriteLine(parts.Length); // 3 Console.WriteLine(parts[1]); // Sara Console.WriteLine(string.Join(" - ", parts)); // Ali - Sara - Reza foreach (string p in parts) Console.WriteLine(p.ToUpper()); string spaced = "a b c"; Console.WriteLine(spaced.Split(' ').Length); // 4 (empty piece between the spaces) Console.WriteLine(spaced.Split(' ', StringSplitOptions.RemoveEmptyEntries).Length); // 3 3 Sara Ali - Sara - Reza ALI SARA REZA 4 3

    اگر کاربر بین کلمه‌ها دو فاصله بگذارد، Split(' ') یک رشته‌ی خالی هم تولید می‌کند. برای شمارش کلمه‌ها یا ساختن نام همیشه از StringSplitOptions.RemoveEmptyEntries استفاده کنید.

    جمله‌ای مثل "I love C#" را بگیرید و کلمه‌هایش را به ترتیب برعکس چاپ کنید: "C# love I".

    مقایسه‌ی رشته‌ها

    Console.WriteLine("apple" == "apple"); // True Console.WriteLine("apple" == "Apple"); // False (case matters) Console.WriteLine("apple".Equals("Apple", StringComparison.OrdinalIgnoreCase)); // True Console.WriteLine(string.Compare("apple", "banana") < 0); // True (apple comes first) Console.WriteLine("b".CompareTo("a") > 0); // True True False True True True

    عملگر == روی رشته‌ها محتوا را مقایسه می‌کند (نه آدرس حافظه)، و به حروف بزرگ و کوچک حساس است. مقایسه‌ی ترتیبی (Compare / CompareTo) مقداری منفی، صفر یا مثبت می‌دهد؛ ترتیب «فرهنگ‌نامه‌ای» مانند ترتیب واژه‌ها در دیکشنری.

    به‌جای a.ToLower() == b.ToLower() که دو رشته‌ی اضافی می‌سازد، از string.Equals(a, b, StringComparison.OrdinalIgnoreCase) استفاده کنید؛ سریع‌تر است و در زبان‌های خاص (مثلاً ترکی با حرف «i» نقطه‌دار و بی‌نقطه) هم رفتار پیش‌بینی‌پذیر دارد. برای رشته‌های فارسی حرف بزرگ و کوچک معنا ندارد، اما یکسان‌سازی «ی/ي» و «ک/ك» یک موضوع جدا و مهم است.

    چسباندن و قالب‌بندی

    string first = "Sara", last = "Karimi"; int age = 20; double price = 1234.56; Console.WriteLine(first + " " + last); // concatenation Console.WriteLine($"{first} {last} is {age} years old"); // interpolation Console.WriteLine($"Price: {price:F1}"); // 1234.6 Console.WriteLine($"Price: {price:N0}"); // 1,235 Console.WriteLine($"|{first,-8}|{age,5}|"); // aligned columns Console.WriteLine(string.Format("{0} / {1}", first, last)); // older style Sara Karimi Sara Karimi is 20 years old Price: 1234.6 Price: 1,235 |Sara | 20| Sara / Karimi
    قالبمعنی
    {x,10}عرض ۱۰ کاراکتر، راست‌چین
    {x,-10}عرض ۱۰ کاراکتر، چپ‌چین
    {x:F2}دو رقم اعشار ثابت
    {x:N0}جداکننده‌ی هزارگان، بدون اعشار
    {x,8:F2}ترکیب: عرض ۸ و دو رقم اعشار

    خروجی N0 و ممیز اعشار به تنظیمات زبان/منطقه‌ی سیستم وابسته است (مثلاً در بعضی سیستم‌ها «.» و «,» جابه‌جا می‌شوند). برای خروجی ثابت می‌توان CultureInfo.InvariantCulture را به کار برد.

    نام و قیمت سه کالا را با {x,-10} و {x,8:F2} به‌صورت جدولی با ستون‌های هم‌تراز چاپ کنید و یک خط جداکننده با new string('-', 18) زیر عنوان بگذارید.

    رشته‌های ویژه: Escape، Verbatim و Raw

    string a = "She said \"hi\"\nand left"; // escapes (\" and \n) string b = @"C:\Users\Ali\file.txt"; // verbatim: backslash is plain string c = """He said "hi" to me"""; // raw string (C# 11) Console.WriteLine(a); Console.WriteLine(b); Console.WriteLine(c); She said "hi" and left C:\Users\Ali\file.txt He said "hi" to me

    رشته‌ی خام با سه علامت نقل‌قول (""") شروع و تمام می‌شود، هر نوع نقل‌قول و بک‌اسلش را بدون escape می‌پذیرد و برای نوشتن JSON، SQL یا متن چندخطی ایده‌آل است. رشته‌ی @"..." هم می‌تواند چندخطی باشد.

    StringBuilder: وقتی زیاد می‌چسبانیم

    چون رشته تغییرناپذیر است، هر بار s += "x" یک رشته‌ی کاملاً جدید می‌سازد و قدیمی دور ریخته می‌شود. برای هزاران بار چسباندن (مثلاً در یک حلقه)، این کار کند است. کلاس StringBuilder یک «بافر قابل‌تغییر» است که کارآمدتر عمل می‌کند.

    using System.Text; var sb = new StringBuilder(); for (int i = 1; i <= 5; i++) { sb.Append(i); if (i < 5) sb.Append(", "); } sb.Append('!'); Console.WriteLine(sb.ToString()); Console.WriteLine(sb.Length); 1, 2, 3, 4, 5! 14

    برای چند چسباندن ساده از + یا $"..." استفاده کنید (خواناتر است). وقتی در حلقه‌ای با تعداد تکرار زیاد متن می‌سازید، سراغ StringBuilder بروید و در پایان ToString() را بزنید.

    الگوهای رایج پردازش متن

    // 1) capitalize first letter string w = "sara"; Console.WriteLine(char.ToUpper(w[0]) + w.Substring(1)); // Sara // 2) count a character string text = "banana"; int count = 0; foreach (char c in text) if (c == 'a') count++; Console.WriteLine(count); // 3 // 3) count a word-part (non-overlapping) int pos = 0, hits = 0; while ((pos = text.IndexOf("an", pos)) != -1) { hits++; pos += 2; } Console.WriteLine(hits); // 2 // 4) palindrome check string p = "level"; bool ok = true; for (int i = 0, j = p.Length - 1; i < j; i++, j--) if (p[i] != p[j]) { ok = false; break; } Console.WriteLine(ok); // True Sara 3 2 True

    جمله‌ای از کاربر بگیرید و بگویید پالیندروم است یا نه (فاصله‌ها و تفاوت حروف بزرگ و کوچک نادیده گرفته شود). مثلاً "never odd or even" پالیندروم است.

    متد static string Caesar(string s, int k) را بنویسید که حروف انگلیسی را k واحد جابه‌جا کند (دورانی، با حفظ بزرگی/کوچکی حروف) و بقیه‌ی کاراکترها را دست‌نخورده بگذارد. با -k هم رمزگشایی شود. نمونه: "Hello, World!" با k = 3 می‌شود "Khoor, Zruog!".

    رشته‌ای و یک زیررشته از کاربر بگیرید و بگویید زیررشته چند بار (بدون هم‌پوشانی) در رشته آمده است و در کدام اندیس‌ها شروع می‌شود. مثال: "banana" و "an" ← ۲ بار، اندیس‌های ۱ و ۳.

    مطالعه‌ی بیشتر

    رشته‌ی سی‌شارپ دنباله‌ای از واحدهای UTF-16 است. حروف فارسی و بیشتر نمادها یک واحد هستند، اما بعضی شکلک‌ها و کاراکترهای نادر دو واحد (surrogate pair) می‌گیرند: "😀".Length برابر ۲ است. همچنین برای چاپ درست فارسی در کنسول باید Console.OutputEncoding = Encoding.UTF8; را بنویسید (با using System.Text;) و فونت کنسول از فارسی پشتیبانی کند؛ ضمناً کنسول متن راست‌به‌چپ را جابه‌جا نشان می‌دهد و این ایراد سی‌شارپ نیست.

    چون رشته تغییرناپذیر است، برای تغییر کاراکتر به کاراکتر می‌توان آن را به آرایه تبدیل کرد: char[] chars = "hello".ToCharArray();، سپس مثلاً Array.Reverse(chars); و در پایان new string(chars) که نتیجه‌اش "olleh" است.

    برای عدد به رشته: x.ToString() یا $"{x}"؛ برای رشته به عدد: int.Parse، int.TryParse یا Convert.ToInt32 (فصل ۸). ارزش‌گذاری "5" + 3 برابر "53" (چسباندن) است، نه ۸.
