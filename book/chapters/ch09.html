    شرط چیست؟

    تا اینجا برنامه‌هایمان یک مسیر ثابت داشتند: خط ۱، بعد خط ۲، بعد خط ۳. اما دنیای واقعی پر از «اگر»هاست: اگر رمز درست بود وارد شو، اگر موجودی کافی بود خرید کن. هر «اگر» یک شرط دارد؛ یعنی عبارتی که نتیجه‌اش فقط true (درست) یا false (نادرست) است، یعنی از نوع bool.

    عملگرهای مقایسه‌ای (رابطه‌ای)

    عملگرمعنیمثال (a=5, b=8)نتیجه
    ==برابر است باa == bFalse
    !=نابرابر است باa != bTrue
    >بزرگ‌ترa > bFalse
    <کوچک‌ترa < bTrue
    >=بزرگ‌تر یا مساویa >= 5True
    <=کوچک‌تر یا مساویb <= 7False

    علامت = یعنی «بریز داخل» (تخصیص) و == یعنی «برابر است؟» (مقایسه). در سی‌شارپ if (x = 5) برای int خطای کامپایل می‌دهد، که خوب است؛ اما برای متغیر bool کد if (flag = true) کامپایل می‌شود و همیشه درست است! مراقب باشید.

    «و» مثل قفل دو‌کلیدی است: هر دو کلید باید باشند تا باز شود. «یا» مثل دو در ورودی است: از هر کدام بیایی می‌توانی وارد شوی. «نقیض» یعنی «برعکس». مثلاً age >= 18 && hasLicense یعنی «هم بزرگسال باشد و هم گواهینامه داشته باشد»؛ اگر یکی نباشد، نتیجه نادرست است.

    اولویت: اول !، بعد &&، بعد ||. با پرانتز مطمئن شوید. همچنین && و || «اتصال کوتاه» دارند: اگر با ارزیابی طرف چپ جواب مشخص شد، طرف راست اصلاً بررسی نمی‌شود. این ویژگی جلوی خطا را می‌گیرد: if (b != 0 && a / b > 2) هیچ‌وقت بر صفر تقسیم نمی‌کند، چون وقتی b صفر است طرف چپ false می‌شود و تقسیم اجرا نمی‌شود.

    دستور if و else

    int score = 72; if (score >= 50) { Console.WriteLine("Pass"); } else { Console.WriteLine("Fail"); }

    اگر else لازم نباشد، فقط if می‌نویسیم؛ در آن صورت اگر شرط نادرست باشد هیچ اتفاقی نمی‌افتد و برنامه خط بعد را ادامه می‌دهد. شرط همیشه داخل پرانتز است و بدنه‌ی هر شاخه در آکولاد.

    1. گذاشتن ; بعد از شرط: if (x > 3); یعنی بدنه‌ی if «خالی» است و خطِ بعدی همیشه اجرا می‌شود (کامپایلر هشدار می‌دهد).
    2. حذف آکولاد با چند دستور: بدون { } فقط یک دستور بعد از if مربوط به آن است. خط‌های بعدی هر چقدر هم تورفتگی داشته باشند، به if ربطی ندارند.
    3. مقایسه‌ی double با ==: به‌خاطر خطای گرد کردن، 0.1 + 0.2 == 0.3 نادرست است (فصل ۵).

    else if؛ چند مسیر

    int score = 85; string grade; if (score >= 90) grade = "A"; else if (score >= 80) grade = "B"; else if (score >= 70) grade = "C"; else grade = "F"; Console.WriteLine($"Grade: {grade}"); Grade: B

    نردبان از بالا شروع می‌کند و با اولین پله‌ی درست متوقف می‌شود. اگر پله‌ی score >= 50 را اول بگذاری، نمره‌ی ۹۵ هم همان‌جا می‌ایستد و هیچ‌وقت به A نمی‌رسد! قاعده: شرط‌های خاص‌تر (سخت‌تر) را بالاتر بگذارید و حالت عمومی را به else بسپارید. دقت کنید در مثال بالا لازم نیست بنویسیم score >= 80 && score < 90؛ چون اگر به این پله رسیده‌ایم یعنی شرط ۹۰ نادرست بوده و نمره‌ی کمتر از ۹۰ است.

    if تو در تو یا ترکیب با &&؟

    int age = 20; bool hasLicense = true; // nested if (age >= 18) { if (hasLicense) Console.WriteLine("You can drive"); } // same meaning, flatter and easier to read if (age >= 18 && hasLicense) Console.WriteLine("You can drive");

    اگه if تو if تو if دیدی که از سه طبقه بیشتره، یعنی یه جای کار بوی بدی می‌ده. 😬 معمولاً می‌شه با && یا با «شرط‌های زودهنگام» ساده‌ش کرد (مثلاً اول حالت‌های خطا رو چک کن و برگرد).

    مقایسه‌ی رشته‌ها

    در سی‌شارپ == روی رشته‌ها «محتوا» را مقایسه می‌کند (برخلاف بعضی زبان‌ها). اما حساس به حروف کوچک و بزرگ است:

    string answer = "Yes"; Console.WriteLine(answer == "yes"); // False Console.WriteLine(answer.ToLower() == "yes"); // True Console.WriteLine(string.Equals(answer, "yes", StringComparison.OrdinalIgnoreCase)); // True

    دستور switch

    وقتی یک متغیر را با چند مقدار ثابت مقایسه می‌کنیم، switch از نردبان طولانی else if خواناتر است.

    Console.Write("Day number (Saturday = 1 ... Friday = 7): "); int day = int.Parse(Console.ReadLine()); switch (day) { case 1: case 2: case 3: case 4: case 5: Console.WriteLine("Working day"); break; case 6: case 7: Console.WriteLine("Weekend"); break; default: Console.WriteLine("Invalid day"); break; }
    • هر case یک مقدار ثابت می‌گیرد (عدد، نویسه یا رشته)، نه یک متغیر یا یک بازه.
    • break اجرای switch را تمام می‌کند. بدون آن کامپایلر خطا می‌دهد (CS0163: Control cannot fall through).
    • چند case پشت‌سرهم بدون دستور بینشان، یک بدنه‌ی مشترک دارند (مثل روزهای ۱ تا ۵ بالا).
    • default مثل else است: وقتی هیچ case منطبق نشد اجرا می‌شود (اختیاری ولی توصیه می‌شود).
    char op = '*'; double x = 6, y = 3; switch (op) { case '+': Console.WriteLine(x + y); break; case '-': Console.WriteLine(x - y); break; case '*': Console.WriteLine(x * y); break; case '/': Console.WriteLine(x / y); break; default: Console.WriteLine("Unknown operator"); break; } 18

    نسخه‌ی مدرن switch یک عبارت است که مستقیماً مقدار برمی‌گرداند (بدون case و break) و از C# 9 می‌تواند بازه هم بپذیرد:

    string name = day switch { 1 => "Saturday", 2 => "Sunday", 3 => "Monday", _ => "Other" // _ means default }; int score = 85; string grade = score switch { >= 90 => "A", >= 80 => "B", >= 70 => "C", _ => "F" };

    اگر شرط‌ها «بازه» یا «ترکیب منطقی» هستند (مثل نمره‌ی بین ۸۰ تا ۸۹) از if / else if استفاده کن. اگر یک مقدار مشخص را با چند حالت ثابت مقایسه می‌کنی (منوی ۱، ۲، ۳؛ روز هفته؛ نوع عملگر) از switch. هر دو درست‌اند؛ هدف «خوانایی» است.

    عملگر شرطی (سه‌تایی): ? :

    این عملگر یک if-else یک‌خطی است که مقدار برمی‌گرداند و تنها عملگر سه‌عملوندی سی‌شارپ است:

    result = condition ? valueIfTrue : valueIfFalse;

    int n = 7; string kind = n % 2 == 0 ? "even" : "odd"; // "odd" string role = "student"; int nationalCode = role == "student" ? 178236 : 265732; // 178236 int a = 12, b = 30; int max = a > b ? a : b; // 30 Console.WriteLine($"{n} is {(n % 2 == 0 ? "even" : "odd")}"); 7 is odd

    داخل رشته‌ی درونیابی ($"...") حتماً عبارت شرطی را داخل پرانتز بگذارید؛ چون : در آنجا برای فرمت‌دهی استفاده می‌شود. همچنین دو مقدار بعد از ? و : باید «هم‌نوع» (یا قابل تبدیل به هم) باشند.

    می‌شه سه‌تایی رو تو در تو نوشت: a ? x : b ? y : z . ولی خوندنش شبیه رمزگشاییِ فیلم‌های جاسوسیه. 🕵️ اگه بیشتر از دو حالت داری، بذار if / else if یا switch expression بنویسه.

    دو عملگر مرتبط با «مقدار نداشتن» (null): عملگر ?? مقدار پیش‌فرض می‌دهد (string name = input ?? "Unknown"; یعنی اگر input برابر null بود، "Unknown") و ?. فقط اگر شیء null نبود به عضو آن دسترسی می‌دهد (text?.Length). در جزوه‌ی شیءگرا به آن‌ها می‌رسیم.

    نمره‌ای (0 تا 100) از کاربر بگیرید و با else if حرف آن را چاپ کنید: ≥۹۰ A، ≥۸۰ B، ≥۷۰ C، ≥۶۰ D، در غیر این صورت F. اگر نمره خارج از ۰ تا ۱۰۰ بود، پیغام «Invalid score» بدهید.

    سالی از کاربر بگیرید و بگویید کبیسه است یا نه. قاعده: بر ۴ بخش‌پذیر باشد، مگر اینکه بر ۱۰۰ بخش‌پذیر باشد؛ ولی اگر بر ۴۰۰ بخش‌پذیر باشد، کبیسه است. (۲۰۰۰ کبیسه است، ۱۹۰۰ نیست.)

    طول سه ضلع را بگیرید. ابتدا بررسی کنید مثلث تشکیل می‌شود (مجموع هر دو ضلع بزرگ‌تر از ضلع سوم). سپس نوع آن را چاپ کنید: متساوی‌الاضلاع، متساوی‌الساقین یا مختلف‌الاضلاع.

    دو عدد و یک عملگر (+ - * /) از کاربر بگیرید و با switch نتیجه را چاپ کنید. در تقسیم بر صفر پیام «Cannot divide by zero» بدهید.

    سه عدد صحیح را بگیرید و بزرگ‌ترین را یک‌بار با if و یک‌بار فقط با عملگر شرطی پیدا کنید.

    این برنامه برای نمره‌ی 95 چه چاپ می‌کند؟ چرا درست کار نمی‌کند و چطور اصلاحش می‌کنید؟

    int score = 95; if (score >= 50) Console.WriteLine("D"); else if (score >= 70) Console.WriteLine("C"); else if (score >= 90) Console.WriteLine("A");
