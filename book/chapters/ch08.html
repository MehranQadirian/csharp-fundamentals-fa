    چرا تبدیل لازم است؟

    یادتان هست که هر متغیر یک جعبه با نوع مشخص است. گاهی مقداری از یک نوع را باید در جعبه‌ی نوع دیگر بریزیم: ورودی کاربر «متن» است ولی ما «عدد» می‌خواهیم؛ نتیجه‌ی یک محاسبه double است ولی باید در int ذخیره شود؛ یک حرف را لازم داریم به شماره‌اش تبدیل کنیم. سی‌شارپ چند راه با درجه‌های مختلف سخت‌گیری برای این کار دارد.

    تبدیل ضمنی (Implicit)

    وقتی مقصد بزرگ‌تر از مبدأ باشد و هیچ داده‌ای از دست نرود، کامپایلر خودش تبدیل می‌کند. به این کار «تبدیل گسترشی» (Widening) هم می‌گویند.

    int small = 100; long big = small; // int -> long : OK double d = small; // int -> double : OK char c = 'A'; int code = c; // char -> int : 65 Console.WriteLine($"{big} {d} {code}"); 100 100 65

    تبدیل long → float ضمنی مجاز است چون گستره‌ی float بزرگ‌تر است، ولی float فقط حدود ۷ رقم دقت دارد؛ پس ممکن است رقم‌های کم‌ارزش از دست بروند (مثلاً مقدار 123456789 در یک float عملاً به 123456792 تبدیل می‌شود). «ضمنی» یعنی «از نظر گستره امن است»، نه اینکه دقت همیشه حفظ شود.

    تبدیل صریح (Cast)

    وقتی از نوع بزرگ به کوچک می‌رویم، ممکن است داده از دست برود؛ پس کامپایلر اجازه نمی‌دهد مگر اینکه خودمان با نوشتن (نوع) قبل از مقدار، صراحتاً بگوییم می‌دانم چه می‌کنم.

    double price = 9.99; // int n = price; // error CS0266: cannot implicitly convert int n = (int)price; // explicit cast Console.WriteLine(n); // 9 (the fraction is cut, not rounded) Console.WriteLine((int)-3.99); // -3 Console.WriteLine((byte)300); // 44 (overflow wraps around) Console.WriteLine((int)3_000_000_000L); // -1294967296 Console.WriteLine((char)66); // B Console.WriteLine((int)'A'); // 65 9 -3 44 -1294967296 B 65

    مکان Cast مهم است. (double)(a / b) اول تقسیم صحیح را انجام می‌دهد و بعد نتیجه را به double تبدیل می‌کند (دیر شده!). Cast باید روی یکی از عملوندها قبل از تقسیم باشد:

    int a = 7, b = 2; Console.WriteLine((double)(a / b)); // 3 (wrong: too late) Console.WriteLine((double)a / b); // 3.5 (right: a becomes double first) Console.WriteLine(a / (double)b); // 3.5 Console.WriteLine(1.0 * a / b); // 3.5 (trick: multiply by 1.0 first)

    کلاس Convert

    کلاس Convert روش «محتاطانه‌تر و همه‌منظوره‌تر» برای تبدیل است: روی انواع مختلف کار می‌کند (عدد، متن، bool، char) و برخلاف Cast، اعشار را گرد می‌کند و اگر مقدار در گستره‌ی مقصد نگنجد استثنا (OverflowException) می‌دهد.

    مقدار(int) CastConvert.ToInt32Math.Round
    9.9991010
    2.5222
    3.5344
    -2.7-2-3-3
    Console.WriteLine(Convert.ToInt32(9.99)); // 10 Console.WriteLine(Convert.ToInt32("123")); // 123 Console.WriteLine(Convert.ToDouble("3.5")); // 3.5 Console.WriteLine(Convert.ToBoolean("true")); // True Console.WriteLine(Convert.ToString(255, 2)); // 11111111 (base 2) Console.WriteLine(Convert.ToString(255, 16)); // ff (base 16) Console.WriteLine(Convert.ToInt32("ff", 16)); // 255 // Convert.ToInt32("12.5"); // FormatException 10 123 3.5 True 11111111 ff 255

    Convert.ToInt32(2.5) برابر 2 است (گرد کردنِ بانکی، مثل Math.Round). اگر عدد «ریاضیِ مدرسه‌ای» می‌خواهید، از Math.Round(x, MidpointRounding.AwayFromZero) استفاده کنید.

    متن به عدد: Parse و TryParse

    هر نوع عددی یک متد Parse دارد که متن را می‌خواند و عدد می‌سازد: int.Parse("42") ، double.Parse("3.14") ، bool.Parse("true") . این همان «عبارت جادویی» فصل ۳ است:

    Console.Write("Enter your age: "); string text = Console.ReadLine(); // always text int age = int.Parse(text); // now a number Console.WriteLine($"Next year you will be {age + 1}");

    مشکل Parse این است که اگر متن نامعتبر باشد (مثلاً کاربر abc تایپ کند) برنامه با FormatException می‌افتد. راه امن TryParse است؛ نتیجه را با یک bool (موفق / ناموفق) می‌دهد و عدد را از طریق out برمی‌گرداند:

    Console.Write("Enter a number: "); string text = Console.ReadLine(); if (int.TryParse(text, out int number)) Console.WriteLine($"Double of it: {number * 2}"); else Console.WriteLine("That is not a valid integer!"); Enter a number: 21 Double of it: 42 Enter a number: 21a That is not a valid integer!

    برای تمرین‌های سریع کلاس Parse کافیه. ولی هر وقت ورودی از آدم‌ها می‌آد، فرض کن یکی می‌خواد برنامه‌ات رو خراب کنه (یا فقط دستش لغزیده 😅). اون‌جا TryParse دوستِ توئه. (دستور if و out رو توی فصل ۹ و ۱۱ کامل می‌بینی؛ فعلاً الگو رو بشناس.)

    در سیستم‌هایی که ویرگول «جداکننده‌ی اعشار» است، double.Parse("3.14") ممکن است خطا بدهد یا نتیجه‌ی غلط بدهد. برای تبدیل مستقل از تنظیمات منطقه، از double.Parse(text, CultureInfo.InvariantCulture) استفاده می‌شود (با using System.Globalization;).

    عدد به متن

    int n = 42; double pi = 3.14159; string s1 = n.ToString(); // "42" string s2 = "Value: " + n; // "Value: 42" string s3 = $"Value: {n}"; // "Value: 42" string s4 = pi.ToString("F2"); // "3.14" string s5 = n.ToString("D5"); // "00042" (at least 5 digits) Console.WriteLine(s4 + " " + s5); 3.14 00042

    char و کد اسکی

    کامپیوتر فقط عدد می‌فهمد. پس برای نگه‌داری حرف‌ها هم یک قرارداد لازم است که به هر نویسه یک شماره بدهد. قدیمی‌ترین قرارداد معروف، جدول ASCII است (۱۲۸ نویسه، کدهای ۰ تا ۱۲۷). نوع char در سی‌شارپ در واقع یک عدد ۱۶ بیتی بدون علامت است که نویسه‌ی Unicode را نمایندگی می‌کند؛ و ۱۲۸ کد اول Unicode با ASCII یکی است.

    char ch = 'A'; int code = (int)ch; // 65 Console.WriteLine($"{ch} -> {code}"); char next = (char)(ch + 1); // 'B' (needs a cast back!) Console.WriteLine(next); Console.WriteLine('a' - 'A'); // 32 (lower/upper difference) Console.WriteLine((char)('a' - 32)); // A (to upper case) Console.WriteLine('7' - '0'); // 7 (digit char -> number) Console.WriteLine((char)('0' + 5)); // 5 (number -> digit char) Console.WriteLine('A' + 1); // 66 (char + int = int!) A -> 65 B 32 A 7 5 66

    حرف '7' یعنی «نویسه‌ی رقم هفت» که در جدول کدش 55 است و '0' کدش 48. پس '7' - '0' یعنی 55 - 48 = 7. ارقام در جدول پشت‌سرهم و به ترتیب هستند؛ بنابراین فاصله‌ی هر رقم تا '0' همان «مقدار» آن رقم است. حروف انگلیسی هم همین‌طورند: 'A'تا 'Z' کدهای ۶۵ تا ۹۰ و 'a' تا 'z' کدهای ۹۷ تا ۱۲۲. اختلاف هر حرف کوچک و بزرگ 32 است.

    توابع کمکی کلاس char

    تابعکارمثال
    char.IsDigit(c)آیا رقم است؟'7' → True
    char.IsLetter(c)آیا حرف است؟'x' → True
    char.IsUpper(c) / IsLower(c)بزرگ یا کوچک بودن'a' → IsUpper False
    char.ToUpper(c) / ToLower(c)تبدیل حالت حروفToUpper('q') → 'Q'
    char.IsWhiteSpace(c)فاصله، تب، خط جدید' ' → True

    به‌جای (char)(c - 32) برای بزرگ کردن حروف، از char.ToUpper(c) استفاده کن. اون کد اسکی‌یه فقط برای حروفِ انگلیسیِ کوچک درسته و روی عدد و علامت و حروف فارسی خرابکاری می‌کنه. حقه‌های اسکی برای فهمیدن ایده‌ست؛ تو پروژه‌ی واقعی از تابع‌های آماده استفاده کن.

    کارگاه عملی: اسکی‌کاو

    این برنامه هر نویسه‌ای را که شما تایپ کنید (حرف، رقم، علامت، حتی حرف فارسی) می‌گیرد و کدش را نشان می‌دهد. چند نویسه‌ی مختلف را امتحان کنید و جدول بالا را با نتیجه تطبیق دهید.

    Console.Write("Type a character: "); char ch = Console.ReadLine()[0]; // first character of the line int code = ch; // implicit char -> int Console.WriteLine($"Character : {ch}"); Console.WriteLine($"Code : {code}"); Console.WriteLine($"Binary : {Convert.ToString(code, 2)}"); Console.WriteLine($"Hex : {Convert.ToString(code, 16)}"); Console.WriteLine($"Next char : {(char)(ch + 1)}"); Type a character: a Character : a Code : 97 Binary : 1100001 Hex : 61 Next char : b

    ASCII فقط حروف انگلیسی و علائم را دارد. برای همه‌ی زبان‌ها استاندارد Unicode ساخته شد که بیش از یک میلیون جایگاه دارد. نویسه‌های فارسی در بلوک U+0600 تا U+06FF هستند: مثلاً (int)'ا' برابر 1575 و (int)'ب' برابر 1576 و (int)'پ' برابر 1662 است. در سی‌شارپ می‌توانید با 'ا' هم همان الف را بنویسید. اگر برنامه‌ی «اسکی‌کاو» را با حرف فارسی اجرا کنید، می‌بینید کدی بزرگ‌تر از ۱۲۷ می‌دهد؛ یعنی دیگر جزو ASCII نیست.

    نکته‌ی ظریف: char یک واحد ۱۶ بیتی UTF-16 است. بعضی نویسه‌ها (مثل ایموجی‌ها) در یک char جا نمی‌شوند و از دو واحد ساخته می‌شوند؛ این موضوع را در کار حرفه‌ای با رشته‌ها خواهید دید.

    bool و تبدیل‌هایش

    برخلاف زبان C، در سی‌شارپ عدد به bool تبدیل نمی‌شود: if (1) یا bool b = 0; خطای کامپایل است. برای تبدیل متن از bool.Parse("true") یا Convert.ToBoolean(...) استفاده می‌شود. نتیجه‌ی چاپ یک bool هم True یا False (با حرف اول بزرگ) است.

    جمع‌بندی: کدام روش، کِی؟

    موقعیتابزار
    تبدیل امن به نوع بزرگ‌ترضمنی (خودکار)
    حذف اعشار یا تبدیل به نوع کوچک‌ترCast: (int)x
    گرد کردن به نزدیک‌ترین صحیحConvert.ToInt32(x) یا Math.Round(x)
    متنِ مطمئن ← عددint.Parse / Convert.ToInt32
    متنِ نامطمئن (ورودی کاربر) ← عددint.TryParse
    هر مقدار ← متنToString() یا $"{x}"
    حرف ↔ کد(int)ch و (char)code

    نتیجه‌ی هر مورد را حدس بزنید و بعد در برنامه بررسی کنید:

    Console.WriteLine((int)7.9); Console.WriteLine((int)-7.9); Console.WriteLine(Convert.ToInt32(7.5)); Console.WriteLine(Convert.ToInt32(8.5)); Console.WriteLine(10 / 4); Console.WriteLine((double)10 / 4); Console.WriteLine((double)(10 / 4)); Console.WriteLine('a' + 2); Console.WriteLine((char)('a' + 2));

    سه عدد صحیح از کاربر بگیرید و میانگین آن‌ها را با دو رقم اعشار چاپ کنید. نسخه‌ی اول را عمداً با تقسیم صحیح بنویسید و خطا را ببینید؛ سپس اصلاحش کنید.

    دو عدد از کاربر بگیرید (با TryParse). اگر هر دو معتبر بودند جمعشان را چاپ کنید و در غیر این صورت پیام خطا بدهید.

    برنامه‌ی «اسکی‌کاو» را طوری گسترش دهید که علاوه بر موارد بالا، حالت حرف مقابل را هم (برای حروف انگلیسی) با char.ToUpper یا char.ToLower چاپ کند. سپس با نویسه‌های A، z، 5، # و یک حرف فارسی آزمایش کنید و جدول نتایج را بنویسید.

    حرف کوچک x را سه واحد به جلو در الفبا ببرید (با چرخش: بعد از z به a برگردد) و نتیجه را چاپ کنید. راهنما: ابتدا c - 'a' را بگیرید، 3 را اضافه و با % 26 محدود کنید و دوباره به 'a' اضافه کنید.
