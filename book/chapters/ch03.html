    اولین برنامه

    سنت برنامه‌نویسی این است که اولین برنامه‌ی هر زبان، جمله‌ی «Hello, World!» را چاپ کند. برنامه‌ی ما این‌طور است:

    using System; class Program { static void Main() { Console.WriteLine("Hello, C#!"); } } Hello, C#!
    جزءنقش
    using System;می‌گوید «از کتابخانه‌ی System استفاده می‌کنم». بدون آن باید به جای Console بنویسیم System.Console.
    class Programهر کد سی‌شارپ داخل یک «کلاس» قرار می‌گیرد. در جزوه‌ی بعد دقیق یاد می‌گیریم کلاس چیست؛ فعلاً آن را یک ظرف بدانید.
    static void Main()نقطه‌ی شروع برنامه. سیستم عامل اجرا را از همین‌جا شروع می‌کند. void یعنی چیزی برنمی‌گرداند و static را در فصل متدها توضیح می‌دهیم.
    { }آکولادها «بدنه» را مشخص می‌کنند؛ هر { باید یک } هم‌جفت داشته باشد.
    Console.WriteLine(...)یک دستور: متن داخل پرانتز را چاپ می‌کند و به خط بعد می‌رود.
    ;پایان هر دستور. شبیه «نقطه» در انتهای جمله.

    در نسخه‌های جدید دات‌نت (از C# 9)، قالب پروژه‌ی کنسول فقط همان یک خط Console.WriteLine("Hello, World!"); را دارد و بقیه را کامپایلر خودش می‌سازد؛ به این قابلیت Top-level statements می‌گویند و دقیقاً معادل برنامه‌ی بالاست. چون در شیءگرایی به ساختار کامل نیاز داریم، در این جزوه شکل کامل را می‌نویسیم. هر دو درست‌اند و کد داخل Main در هر دو یکی است.

    اجرای برنامه

    • Visual Studio: کلید Ctrl+F5 (اجرا بدون دیباگ؛ بعد از پایان، پنجره باز می‌ماند) یا F5 (اجرا با دیباگ).
    • ترمینال: داخل پوشه‌ی پروژه دستور dotnet run.
    • آنلاین: دکمه‌ی Run در dotnetfiddle.

    اگه با F5 اجرا کنی و پنجره‌ی سیاه یه لحظه بپره و ببنده، نترس؛ برنامه‌ات درسته، فقط اجراش تموم شده و پنجره هم بسته شده. با Ctrl+F5 اجرا کن، یا یه خط Console.ReadLine(); آخر برنامه بذار تا منتظر Enter بمونه.

    Console.WriteLine و Console.Write

    هر دو متن را روی صفحه چاپ می‌کنند. تنها تفاوت‌شان در جای مکان‌نما بعد از چاپ است:

    • Console.WriteLine(x): ابتدا x را چاپ می‌کند، سپس به ابتدای خط بعد می‌رود.
    • Console.Write(x): فقط x را چاپ می‌کند و مکان‌نما همان‌جا می‌ماند.
    Console.WriteLine("Line one"); Console.WriteLine("Line two"); Console.Write("Hello, "); Console.Write("World"); Console.WriteLine("!"); Console.WriteLine(); // an empty line Console.WriteLine("The end"); Line one Line two Hello, World! The end

    چاپ عدد و عبارت

    Console.WriteLine(5 + 3); // the sum is calculated first Console.WriteLine("5 + 3"); // text inside quotes is printed as is Console.WriteLine("Sum: " + (5 + 3)); Console.WriteLine("Sum: " + 5 + 3); // careful! 8 5 + 3 Sum: 8 Sum: 53

    کامپایلر از چپ به راست کار می‌کند. اول "Sum: " + 5 را می‌بیند؛ طرف چپ متن است، پس عدد 5 را هم «متن» حساب می‌کند و می‌شود "Sum: 5". بعد "Sum: 5" + 3 می‌شود "Sum: 53". یعنی علامت + وقتی یک طرفش متن باشد، «چسباندن» است نه «جمع کردن». برای اینکه اول جمع انجام شود، باید پرانتز بگذاریم، مثل خط سوم.

    توضیحات (Comment)

    توضیحات برای انسان‌ها نوشته می‌شوند و کامپایلر آن‌ها را نادیده می‌گیرد.

    // A single-line comment /* A multi-line comment */ Console.WriteLine("Hi"); // a comment after a statement

    کامنت نذار که «چی» کار می‌کنه (// چاپ می‌کنه برای Console.WriteLine فایده‌ای نداره!). کامنت بنویس که «چرا». شش ماه دیگه خودت هم کدی که امروز نوشتی رو نمی‌فهمی؛ کامنت خوب یعنی نامه‌ای به خودِ آینده‌ت. 💌

    خواندن ورودی از کاربر

    دستور Console.ReadLine() برنامه را متوقف می‌کند تا کاربر چیزی تایپ کند و Enter بزند؛ سپس هر چه تایپ شده را به‌صورت متن (string) برمی‌گرداند.

    Console.Write("What is your name? "); string name = Console.ReadLine(); Console.WriteLine("Hello, " + name + "!"); What is your name? Sara Hello, Sara!

    ReadLine همیشه «متن» می‌دهد، حتی اگر کاربر 25 تایپ کند. برای گرفتن عدد، از این الگو استفاده کنید: int age = int.Parse(Console.ReadLine()); . فعلاً آن را یک «عبارت جادویی» بدانید؛ در فصل «تبدیل انواع» (فصل ۸) دقیق توضیح می‌دهیم که چرا کار می‌کند و اگر کاربر چیز نامعتبر وارد کند چه می‌شود.

    { بدون }آکولاد ناجورerror CS1513: } expected

    برنامه‌ای بنویسید که اطلاعات خودتان را در ۴ خط چاپ کند (نام، رشته، دانشگاه، یک علاقه‌مندی). از فقط Console.WriteLine استفاده کنید.

    خروجی دقیق این کد چیست؟ (بدون اجرا کردن حدس بزنید، بعد آزمایش کنید)

    Console.Write("A"); Console.Write("B"); Console.WriteLine("C"); Console.WriteLine("D"); Console.Write("E"); Console.WriteLine(2 + 3); Console.WriteLine("2" + 3);

    با Console.WriteLine یک مثلث ستاره‌ای با ارتفاع ۴ خط چاپ کنید (خط اول یک ستاره، خط دوم دو ستاره و…).
