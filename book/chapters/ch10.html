    چرا حلقه؟

    فرض کنید باید اعداد ۱ تا ۱۰۰۰ را چاپ کنید. با آنچه تا حالا یاد گرفتیم باید ۱۰۰۰ خط Console.WriteLine بنویسیم! حلقه (Loop) به برنامه می‌گوید «این بلوک کد را تا وقتی شرطی برقرار است، تکرار کن». قدرت واقعی کامپیوتر دقیقاً همین‌جاست: انجام میلیون‌ها کار تکراری بدون خستگی.

    // without a loop (not scalable!) Console.WriteLine(1); Console.WriteLine(2); Console.WriteLine(3); // ... 997 more lines // with a loop (any number of lines) for (int i = 1; i <= 1000; i++) { Console.WriteLine(i); }

    هر حلقه‌ای، با هر ظاهری، همین چهار سؤال را جواب می‌دهد: ۱) از کجا شروع کنم؟ ۲) تا کِی ادامه بدهم؟ (شرط) ۳) در هر دور چه کار کنم؟ (بدنه) ۴) بعد از هر دور چه چیزی را تغییر بدهم تا بالاخره تمام شود؟ اگر جواب سؤال چهارم را فراموش کنی، حلقه‌ات هیچ‌وقت تمام نمی‌شود، مثل پلی‌لیستی که روی تکرار مانده و هیچ‌کس دکمه‌ی توقف را نمی‌زند.

    حلقه‌ی for

    وقتی تعداد تکرار از قبل معلوم است، for بهترین انتخاب است؛ چون چهار قسمت حلقه را در یک خط کنار هم می‌نویسد:

    for (int i = 1; i <= 3; i++) { Console.WriteLine("Round " + i); }

    متغیری که داخل پرانتز for تعریف می‌شود (int i) فقط داخل همان حلقه شناخته می‌شود. بعد از آکولاد پایانی، i دیگر وجود ندارد. اگر مقدار نهایی را بعد از حلقه لازم دارید، متغیر را قبل از حلقه تعریف کنید.

    شکل‌های مختلف for

    for (int i = 10; i >= 0; i -= 2) Console.Write(i + " "); // 10 8 6 4 2 0 Console.WriteLine(); for (int i = 1; i <= 100; i *= 2) Console.Write(i + " "); // 1 2 4 8 16 32 64 Console.WriteLine(); for (int i = 0, j = 10; i < j; i++, j--) // two counters Console.Write($"({i},{j}) "); 10 8 6 4 2 0 1 2 4 8 16 32 64 (0,10) (1,9) (2,8) (3,7) (4,6)

    حلقه‌ی while

    وقتی نمی‌دانیم چند بار تکرار می‌شود و فقط «تا وقتی شرطی برقرار است» ادامه می‌دهیم، از while استفاده می‌کنیم. شرط قبل از هر دور بررسی می‌شود؛ پس ممکن است حتی یک‌بار هم اجرا نشود. مقدار اولیه را باید خودمان قبل از حلقه و تغییر را داخل بدنه بنویسیم.

    int n = 4729; // 1) start int sum = 0; while (n > 0) // 2) condition { sum += n % 10; // 3) body: take the last digit n /= 10; // 4) update: remove the last digit } Console.WriteLine(sum); // 22

    حلقه‌ی do-while

    شبیه while است با یک تفاوت مهم: اول بدنه اجرا می‌شود و بعد شرط بررسی می‌شود. پس بدنه حداقل یک‌بار اجرا می‌شود. مثال کلاسیک: گرفتن ورودی معتبر، چون حداقل یک‌بار باید از کاربر بپرسیم.

    int age; do { Console.Write("Enter your age (1-120): "); age = int.Parse(Console.ReadLine()); } while (age < 1 || age > 120); // note the semicolon! Console.WriteLine("Accepted: " + age);

    در انتهای do { ... } while (شرط); حتماً ; بنویسید. در while و for معمولی بعد از پرانتز شرط نباید ; بگذارید (بدنه را خالی می‌کند).

    الگوی انباشت (Accumulator)

    پرکاربردترین الگوی حلقه‌ها: یک متغیر «نتیجه» که در هر دور تغییر می‌کند. مثلاً جمع ۱ تا ۴:

    هدفمقدار اولیهبه‌روزرسانی در هر دور
    مجموعsum = 0sum += x;
    حاصل‌ضرب (فاکتوریل)product = 1product *= x;
    شمارشcount = 0count++; (فقط وقتی شرط برقرار است)
    بیشینهاولین عنصر (یا کمترین مقدار ممکن)if (x > max) max = x;
    int n = 5; long factorial = 1; // 1, not 0! for (int i = 2; i <= n; i++) factorial *= i; Console.WriteLine($"{n}! = {factorial}"); // 5! = 120

    مقدار اولیه‌ی جمع 0 است چون عنصر خنثای جمع است؛ اما مقدار اولیه‌ی ضرب 1 است. اگر فاکتوریل را با 0 شروع کنید، همه‌ی جواب‌ها صفر می‌شوند!

    break و continue

    • break: حلقه را کلاً رها می‌کند و می‌پرد به بعد از حلقه.
    • continue: همین دور را رها می‌کند و می‌رود سراغ دور بعد (در for ابتدا به‌روزرسانی انجام می‌شود).
    for (int i = 1; i <= 10; i++) { if (i % 2 == 0) continue; // skip even numbers if (i > 7) break; // stop completely Console.Write(i + " "); } 1 3 5 7 int secret = 7; while (true) // infinite loop on purpose { Console.Write("Guess: "); int guess = int.Parse(Console.ReadLine()); if (guess == secret) { Console.WriteLine("Correct!"); break; // the only way out } Console.WriteLine(guess < secret ? "Higher" : "Lower"); }

    حلقه‌ی بی‌نهایت while (true) همیشه بد نیست؛ تو بازی‌ها و منوها حتی استاندارده، به شرطی که یه break یا return براش بذاری. و اگه ناخواسته تو حلقه‌ی بی‌نهایت گیر کردی و کنسول هنگ کرد، Ctrl + C برنامه رو متوقف می‌کنه (تو Visual Studio دکمه‌ی Stop قرمزه).

    حلقه‌های تودرتو

    درون بدنه‌ی یک حلقه می‌توان حلقه‌ی دیگری گذاشت. حلقه‌ی درونی در هر دورِ حلقه‌ی بیرونی از اول و کامل اجرا می‌شود. مثل ساعت: عقربه‌ی دقیقه ۶۰ دور کامل می‌زند تا عقربه‌ی ساعت یک قدم بردارد.

    for (int i = 1; i <= 3; i++) // rows { for (int j = 1; j <= 4; j++) // columns { Console.Write($"{i * j,4}"); } Console.WriteLine(); // after each row } 1 2 3 4 2 4 6 8 3 6 9 12

    الگوهای ستاره‌ای

    for (int i = 1; i <= 4; i++) { for (int j = 1; j <= i; j++) Console.Write("*"); Console.WriteLine(); } * ** *** ****
    for (int i = 1; i <= 4; i++) { for (int s = 1; s <= 4 - i; s++) Console.Write(" "); for (int k = 1; k <= 2 * i - 1; k++) Console.Write("*"); Console.WriteLine(); } * *** ***** *******

    برای هر الگوی چاپی سه سؤال بپرس: ۱) چند سطر دارد؟ (حلقه‌ی بیرونی) ۲) در سطر i چند فاصله لازم است؟ ۳) در سطر i چند ستاره؟ مثلاً در هرم، سطر i دارای 4 − i فاصله و 2i − 1 ستاره است. اول فرمول هر سطر را روی کاغذ پیدا کن، بعد کد بنویس.

    الگوهای پرکاربرد

    معکوس یک عدد

    int n = 1234, rev = 0; while (n > 0) { rev = rev * 10 + n % 10; // append the last digit of n to rev n /= 10; } Console.WriteLine(rev); // 4321

    عدد اول

    int n = 29; bool isPrime = n >= 2; for (int i = 2; i * i <= n; i++) // checking up to sqrt(n) is enough { if (n % i == 0) { isPrime = false; break; // one divisor is enough } } Console.WriteLine(isPrime); // True

    اگر n مقسوم‌علیه بزرگی مثل a داشته باشد، باید مقسوم‌علیه کوچکی مثل b = n/a هم داشته باشد که حداکثر برابر √n است. پس اگر تا √n مقسوم‌علیه‌ای پیدا نشد، بعد از آن هم پیدا نمی‌شود. این بهینه‌سازی برای n=۱ میلیارد حدود ۳۱ هزار تکرار به جای یک میلیارد تکرار است!

    اشتباه‌های رایج در حلقه‌ها

    1. فراموش کردن به‌روزرسانی: در while (i <= 5) { Console.WriteLine(i); } هیچ‌وقت i عوض نمی‌شود؛ حلقه‌ی بی‌نهایت!
    2. شمارنده‌ی اعشاری: for (double x = 0; x != 1.0; x += 0.1) هرگز به ۱٫۰ دقیق نمی‌رسد (به‌خاطر خطای گرد کردن) و تمام نمی‌شود. از شمارنده‌ی int یا شرط < استفاده کنید.
    3. تغییر شمارنده داخل بدنه: دست‌کاری i وسط بدنه‌ی for، ردیابی را سخت می‌کند.
    4. مقدار اولیه‌ی اشتباه انباشت: جمع با ۰ و ضرب با ۱ شروع می‌شود.

    کدام حلقه را انتخاب کنم؟

    حلقهبررسی شرطحداقل اجرامناسب برای
    forقبل از هر دور۰ بارتعداد تکرار مشخص؛ شمارنده‌دار
    whileقبل از هر دور۰ بارتکرار تا برقراری شرط؛ تعداد نامشخص
    do-whileبعد از هر دور۱ بارمنو و ورودی معتبر؛ باید حداقل یک‌بار اجرا شود

    وقتی حلقه‌ات جواب عجیب می‌ده، حلقه رو توی ذهنت اجرا نکن؛ داخل بدنه یه Console.WriteLine($"i={i}, sum={sum}"); بذار. دیدن مقدار متغیرها تو هر دور، ۹۰٪ باگ‌ها رو لو می‌ده. بعدش با F9 (breakpoint) و F10 (قدم‌به‌قدم) تو Visual Studio حرفه‌ای‌تر هم می‌شه.

    اعداد زوج بین ۱ تا ۵۰ را چاپ کنید: یک‌بار با گام ۲ در for و یک‌بار با بررسی % 2 داخل حلقه.

    ابتدا N را بپرسید، سپس N عدد بگیرید و مجموع و میانگین آن‌ها را (با دو رقم اعشار) چاپ کنید.

    عدد n را بگیرید و جدول ضرب آن را از ۱ تا ۱۰ به شکل n x i = result چاپ کنید.

    الف) مثلث وارونه با ارتفاع ۵ (۵ ستاره در سطر اول و ۱ ستاره در سطر آخر). ب) مربع توخالی ۵×۵ (فقط حاشیه ستاره باشد).

    برنامه‌ی «حدس عدد» بنویسید که عدد مخفی را (مثلاً ۷۷) ثابت نگه دارد و تا وقتی کاربر درست حدس نزده، راهنمایی «Higher/Lower» بدهد و در پایان تعداد تلاش‌ها را چاپ کند.

    عددی بگیرید و تعداد ارقام، مجموع ارقام و معکوس آن را بنویسید. سپس بگویید عدد «متقارن» (پالیندروم) است یا نه (مثل ۱۲۳۲۱).
