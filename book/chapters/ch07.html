    Math چیست؟

    Math یک کلاس آماده در کتابخانه‌ی System است که مجموعه‌ای از توابع ریاضی را در اختیار ما می‌گذارد. ما نیازی به ساخت چیزی نداریم؛ فقط می‌نویسیم Math. و نام تابع و ورودی‌ها را داخل پرانتز می‌دهیم. تابع نتیجه را برمی‌گرداند و باید آن را در متغیر بریزیم یا چاپ کنیم.

    double root = Math.Sqrt(144); // 12 double p = Math.Pow(2, 10); // 1024 Console.WriteLine(Math.Max(3, 7)); // 7

    هر تابع Math مثل یک دکمه‌ی ماشین‌حساب است: ورودی می‌دهی، دکمه را می‌زنی و جواب بیرون می‌آید. لازم نیست بدانی داخلش چطور ریشه حساب می‌شود؛ فقط باید بدانی چه می‌گیرد و چه برمی‌گرداند. همین ایده را در فصل ۱۱ برای ساختن تابع‌های خودمان به کار می‌بریم.

    ثابت‌های ریاضی

    Console.WriteLine(Math.PI); // 3.141592653589793 Console.WriteLine(Math.E); // 2.718281828459045 Console.WriteLine(Math.Tau); // 6.283185307179586 (2 * PI) 3.141592653589793 2.718281828459045 6.283185307179586

    گرد کردن: Floor و Ceiling و Round و Truncate

    چهار تابع برای رسیدن از یک عدد اعشاری به عدد صحیح وجود دارد و رفتارشان با اعداد منفی فرق می‌کند. بهتر است آن‌ها را روی خط اعداد ببینیم:

    تابعقانون2.7-2.72.5
    Math.Floorبه سمت پایین (کف)2-32
    Math.Ceilingبه سمت بالا (سقف)3-23
    Math.Truncateحذف اعشار (به سمت صفر)2-22
    Math.Roundبه نزدیک‌ترین صحیح3-32 (!)
    Console.WriteLine(Math.Round(2.5)); // 2 (!) Console.WriteLine(Math.Round(3.5)); // 4 Console.WriteLine(Math.Round(-2.5)); // -2 Console.WriteLine(Math.Round(2.5, MidpointRounding.AwayFromZero)); // 3 Console.WriteLine(Math.Round(2.567, 2)); // 2.57 (2 decimals) 2 4 -2 3 2.57

    به‌طور پیش‌فرض، Math.Round وقتی دقیقاً وسط دو عدد باشد (مثل 2.5)، به سمت عدد زوج نزدیک می‌رود (2.5→2 و 3.5→4). به این روش «گرد کردن بانکی» می‌گویند که در جمع‌های بزرگ خطا را کم می‌کند. اگر گردکردن «مدرسه‌ای» می‌خواهید (۲٫۵ ← ۳) از MidpointRounding.AwayFromZero استفاده کنید. تعداد ارقام اعشار در Round(x, digits) باید بین 0 و 15 باشد (مقدار منفی خطای زمان اجرا می‌دهد).

    یه ترفند تمیز: برای گرد کردن 1234 به نزدیک‌ترین 100: Math.Round(1234 / 100.0) * 100 ← می‌شه 1200. اول تقسیم می‌کنی، گرد می‌کنی، بعد دوباره ضرب. همین ایده برای هر مضربی جواب می‌ده.

    مثلثات

    توابع Sin، Cos، Tan و معکوس‌هایشان Asin، Acos، Atan زاویه را بر حسب رادیان می‌گیرند و می‌دهند، نه درجه. برای تبدیل: رادیان = درجه × π / 180.

    double deg = 30; double rad = deg * Math.PI / 180; Console.WriteLine(Math.Sin(rad)); // 0.49999999999999994 Console.WriteLine(Math.Round(Math.Sin(rad), 2)); // 0.5 Console.WriteLine(Math.Cos(Math.PI)); // -1 Console.WriteLine(Math.Sin(Math.PI)); // 1.2246467991473532E-16 (not exactly 0) Console.WriteLine(Math.Atan(1) * 180 / Math.PI); // 45 Console.WriteLine(Math.Asin(0.5) * 180 / Math.PI); // 30.000000000000004 Console.WriteLine(Math.Round(Math.Asin(0.5) * 180 / Math.PI)); // 30 Console.WriteLine(Math.Acos(0) * 180 / Math.PI); // 90 Console.WriteLine(Math.Atan2(1, 1)); // 0.7853981633974483 0.49999999999999994 0.5 -1 1.2246467991473532E-16 45 30.000000000000004 30 90 0.7853981633974483
    تابعکار
    Sin / Cos / Tanسینوس، کسینوس، تانژانت (ورودی: رادیان)
    Asin / Acos / Atanمعکوس‌ها؛ خروجی رادیان؛ Asin (آرک‌سینوس: زاویه‌ای که سینوسش برابر ورودی است) و Acos فقط ورودی بین ‎-1 و 1 می‌گیرند
    Atan2(y, x)زاویه‌ی نقطه‌ی (x, y) با محور x در ناحیه‌ی درست (از ‎-π تا π)
    Sinh / Cosh / Tanhتوابع هذلولوی

    خود π هم دقیق ذخیره نمی‌شود؛ Math.PI یک تقریب با حدود ۱۶ رقم است. وقتی سینوس چیزی را که «کمی با π فرق دارد» حساب می‌کنیم، جواب هم «کمی با صفر فرق دارد»: 1.22E-16 یعنی ۰٫۰۰۰…۰۱۲۲ با ۱۵ صفر! برای چاپ، Math.Round(x, 2) یا فرمت :F2 را به کار ببرید.

    رفتارهای ویژه و خطاها

    Console.WriteLine(Math.Sqrt(-1)); // NaN (no real root) Console.WriteLine(Math.Log(0)); // -Infinity Console.WriteLine(Math.Pow(0, 0)); // 1 Console.WriteLine(Math.Max(5, 5.5)); // 5.5 (int is converted to double) var (q, r) = Math.DivRem(17, 5); // tuple deconstruction Console.WriteLine($"{q} remainder {r}"); // Math.Abs(int.MinValue); // OverflowException! NaN -Infinity 1 5.5 3 remainder 2

    بیشتر توابع Math مقدار double برمی‌گردانند. int n = Math.Sqrt(16); خطا می‌دهد؛ چون double داخل int جا نمی‌شود. باید تبدیل صریح کرد: int n = (int)Math.Sqrt(16); (فصل بعد) یا خروجی را در double نگه داشت.

    Random جزو Math نیست ولی همراهش استفاده می‌شود. در .NET 6 به بعد: int dice = Random.Shared.Next(1, 7); یک عدد از 1 تا 6 می‌دهد (کران بالا شامل نمی‌شود) و Random.Shared.NextDouble() یک عدد اعشاری بین 0 و کمتر از 1 می‌دهد. برای اعداد تصادفی امن در رمزنگاری از RandomNumberGenerator استفاده می‌شود.

    دو ضلع قائم یک مثلث قائم‌الزاویه (مثلاً 3 و 4) را در دو متغیر بگذارید و طول وتر را با Math.Sqrt و Math.Pow حساب کنید.

    شعاع دایره را در متغیر بگذارید و مساحت و محیط را با دو رقم اعشار چاپ کنید (از Math.PI استفاده کنید).

    فاصله‌ی نقطه‌ی (1, 2) تا (4, 6) را با فرمول √((x₂−x₁)² + (y₂−y₁)²) حساب کنید.

    با فرمول A = P × (1 + r)n مبلغ سپرده‌ای با اصل 1000 و نرخ سالانه‌ی 0.2 (۲۰٪) را پس از 3 سال حساب کنید.

    برای عدد -4.5 و 4.5 نتیجه‌ی Floor، Ceiling، Truncate و Round (پیش‌فرض) را پیش‌بینی کنید و سپس برنامه بنویسید و بررسی کنید.

    زاویه‌ی 60 درجه را به رادیان تبدیل و سینوس و کسینوس آن را با دو رقم اعشار چاپ کنید. بنویسید چرا اگر درجه را مستقیم به Math.Sin بدهیم جواب غلط می‌شود.
